# genshin.cat 🐾

A cozy Genshin Impact companion website made for my girlfriend 💕

## What's Inside
- **Roster & Weapons:** Browse all characters and weapons in alphabetical order with clean element and region info.
- **Meta Tier List:** Clean patch rankings for Spiral Abyss and endgame teams.
- **Team Composer:** Build 4-person teams to view elemental resonances, reaction synergies, and team balance.
- **Interactive Map:** Quick in-app Teyvat interactive map for finding chests, oculi, and materials.
- **Tools:** Material planner, domain schedule, and weekly boss tracker.

## Quick Start
Open `index.html` in your browser, or run a local dev server:
```bash
npm install
npm start
```
Runs at `http://localhost:5173/` by default.
